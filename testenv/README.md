# 测试环境（testenv）说明

这个目录专门用来存放运行时产生的数据与自证日志，**全部不入版本库**：

- `status.log`        程序运行自证日志（含真实姓名/学号）
- `名单.csv`          导入的原始名单（含真实学生信息）
- `workspace.json`    工作区（人员 + 组织 + 多对多关系 + 组序 + 历史）
- `*.xlsx / *.csv`    任何真实名单与导出文件
- `*.log`             所有日志

请把在 GUI 里导入的名单、保存的「加载工作区」、以及运行产生的日志都放到这里。
`./picker_cli` 默认文件与 GUI 自动加载的工作区路径已改为 `./testenv/workspace.json`。

⚠️ 含真实学生姓名的数据永远不要提交到仓库。
